# 答题助手 · 安装说明

> 包名：`__PKG_NAME__` ｜ 版本：`__VERSION__` ｜ 打包时间：`__BUILD_TIME__`

---

## 一、这是什么

一个 Windows 桌面小工具：**框住屏幕上的题目区域 → 自动 OCR → 到本地题库里模糊匹配 → 浮窗显示答案与解析**。
用于随堂练习、培训考核这类需要快速对照题库的场景。

安装包是**完全自包含、完全离线**的，里面已经带好了运行所需的一切：

| 组成部分 | 内容 | 说明 |
| --- | --- | --- |
| `runtime\python\` | 便携版 Python 3.13.15 | 含 tkinter（GUI 必需），无需系统装 Python |
| `.venv\` | 预装好的全部依赖 | PaddleOCR / PaddlePaddle / OpenCV / numpy 等 |
| `models\` | OCR 模型（PP-OCRv5/v6） | 离线识别用，安装时不需要联网下载 |
| `core\ ui\ workers\ tools\` | 程序源码 | 出问题可以直接看代码、改代码 |
| `data\` | 你的配置与题库样本 | 第一次运行后生成 |

**目标机器上不需要预装 Python，不需要联网，不需要管理员权限。**

## 二、适用范围

### 支持

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11 |
| 架构 | **64 位 x86-64**（ARM 版 Windows 需自行验证，未测试） |
| 用途 | 单机离线使用；题库为本地文件 |
| 显示器 | 单屏 / 多屏都可以；系统缩放 100% ~ 200% |
| 权限 | 普通用户即可，**不需要管理员** |
| 网络 | **完全不需要**（识别、匹配、题库解析全在本地） |

### 不支持

- **Windows 7 / 8 / 8.1** —— 附带的 Python 3.13 与 PaddlePaddle 都不支持这些老系统
- **32 位 Windows** —— 附带的运行时是 x86-64，且 PaddlePaddle 早已停止 32 位支持
- **macOS / Linux** —— 程序大量使用 Windows API（DPI 感知、窗口置顶、屏幕抓取），未做跨平台
- **无图形界面的服务器核心版** —— 需要桌面会话才能截图与显示浮窗
- **把程序当服务器多用户共用** —— 它是单用户桌面工具，配置与浮窗状态都是进程内的

## 三、使用前提

### 硬件

| 项目 | 最低 | 建议 |
| --- | --- | --- |
| CPU | 64 位双核 | **四核及以上**（OCR 是纯 CPU 计算，核心越多越快） |
| 内存 | 4 GB | **8 GB 及以上**（OCR 模型常驻约 1.5 ~ 2.5 GB） |
| 磁盘 | 解压后约 0.85 GB 可用空间 | 建议留 2 GB（首次运行生成字节码缓存、日志与题库会增长） |
| 显卡 | 无要求 | 用不到 GPU，程序走 CPU 推理 |

### 安装位置

- **不要**装在 `C:\Program Files\`、`C:\Program Files (x86)\` 这类只读目录
- **不要**放在网盘同步目录（OneDrive / Dropbox）里长期运行，同步会干扰且拖慢启动
- **建议用纯英文路径**，例如 `D:\AnswerAssistant\`
  （路径含中文时虚拟环境的 `pyvenv.cfg` 编码可能有兼容问题，虽然已做兼容处理，但英文路径最稳）
- 可以直接装在 U 盘里带走，但换机器后**必须重新跑一次 `install.bat`**（它会重写环境路径）

### 系统层面

- 防火墙 / 杀毒软件**不需要放行任何网络端口**，程序不联网
- 但杀毒软件可能对 `cv2.pyd`、`paddle` 的 DLL 报"可疑"，属于误报（这些是 OpenCV 与 PaddlePaddle 的官方二进制），必要时加白名单
- 热键用的是全局键盘钩子（`keyboard` 库），个别安全软件会拦截全局钩子导致 F1~F9 失效，此时需要放行

### 题库

- 支持格式：`.xlsx` / `.xlsm` / `.csv` / `.tsv` / `.json` / `.docx` / `.doc` / `.txt` / `.md`
- 标准考试模板（`题型*` `题目*` `选项` `答案*` `解析` 列）可直接导入
- 选项支持 `A. xxx` / `A、xxx` / `(A) xxx` 以及多行、竖线、空格分隔的写法
- Word 题库的**真实格式按文件头判定**，不看扩展名：Word 97-2003 与 OOXML 都能读，
  中文办公环境里「另存为 .doc 但名字还是 .docx」的文件不会再导入失败

## 四、安装步骤

1. **完整解压**这个压缩包到一个磁盘目录，例如 `D:\AnswerAssistant\`
   - 必须解压后再操作，**不要在压缩软件里直接双击运行**
2. 双击 **`install.bat`**
   - 它会重写虚拟环境路径、补齐可写目录、校验依赖与模型，最后跑一次自检
   - 全部离线完成，通常 **10 秒以内**
3. 双击 **`run.bat`** 启动（无控制台窗口）
   - 排错时改用 `run_debug.bat`，会留一个日志窗口
4. 首次使用：控制面板 → 导入题库（或点"生成示例题库"先试）

> 如果换了目录、换了机器、或者从 U 盘挪到硬盘，**重新跑一次 `install.bat` 即可**。

## 六、已知限制

- **识别速度**：约 0.3 秒/行文字。典型一道题 3~4 秒，整屏 30 多行要 12~13 秒。
  想更快就**把识别框圈小**，这是唯一有效的办法（调小截屏间隔没用，间隔只管"画面变了多久被发现"）。
- **CPU 占用**：识别态下搜索进程会跑满约 4 个核心（已按 `ocr_threads` 封顶，可在设置里调）。
- **仅 Windows**，且需要图形桌面会话。
- **题库是本地文件**，程序不含任何题库内容，也不联网校验。
- **首次启动会慢一些**：安装包为了减小体积，没有携带 Python 字节码缓存（`.pyc`）。
  第一次运行会现场编译并缓存到程序目录，大约多花 10~30 秒，之后启动就快了。
  这个缓存会让程序目录最多增加约 150 MB，属于正常的自我优化，不是异常。
- **`pip check` 会报一条 `huggingface-hub requires hf-xet`**：这是打包时精简掉的可选加速组件，
  离线场景用不到，不影响任何功能，可以忽略。
- **不要把日志 / 配置当垃圾清掉**：`data\config.json` 是你的全部设置（题库路径、扫描区域、按键绑定）。

## 七、卸载

直接删除整个目录即可，不留注册表项、不留系统服务。

用户数据都在程序目录下的 `data\` 里（`config.json` 与示例题库），
如果只想卸载程序、保留题库，先把 `data\` 备份出来。
模型在 `models\` 内，不会写到你的用户目录。

## 八、排错

**双击 `install.bat` 一闪而过 / 报 `runtime\python\python.exe not found`**
→ 没有完整解压，或者解压时漏了 `runtime` 目录。重新完整解压。

**`install.bat` 报 "虚拟环境无法启动"**
→ 多半是路径含中文或特殊字符。把整个文件夹移到纯英文路径下重跑。

**`run.bat` 点了没反应**
→ 改用 `run_debug.bat`，看窗口里的报错；日志也在 `logs\app.log`。

**提示"没有可用的 OCR 引擎"**
→ 确认 `models\paddlex\official_models\` 下有 4 个模型目录。
  缺失就重新完整解压（模型约 154 MB）。

**F1~F9 全局热键没反应**
→ 安全软件拦截了全局键盘钩子。放行本程序，或用控制面板上的按钮代替热键。

**识别很慢**
→ 这是正常的 CPU OCR 速度。把识别框圈到只覆盖题干，别圈整屏。

**界面 / 选区偏移**
→ 超高缩放（>200%）或多显示器混合 DPI 的情况下可能偏移，把系统缩放调整为整数倍（100%/125%/150%）后重启程序。

## 九、怎么确认这份包是好的

双击 `install.bat`，最后一步会跑一遍自检。看到下面这两行就说明环境没问题：

```
 结果：N 通过 / M 警告 / 0 失败
全部关键检查通过，可以运行 run.bat 启动程序。
```

**只要「失败」是 0 就不用管「警告」**。常见警告及含义：

| 警告 | 含义 |
| --- | --- |
| `可选依赖: 未安装：RapidOCR 引擎（备用）` | 打包时精简掉的备用引擎，用不到，PaddleOCR 已经够用 |
| `引擎 rapid: 初始化失败` | 同上，同一个原因 |

更细的排错：

```
.venv\Scripts\python.exe tools\selfcheck.py           完整自检（含 OCR 与三进程）
.venv\Scripts\python.exe tools\selfcheck.py --quick   跳过 OCR，秒级出结果
```

## 十、本包包含的修复

| 版本 | 修复内容 |
| --- | --- |
| 1.0.0 | 表格题库的选项错位：正则捕获组导致选项字母被当成选项正文，浮窗出现过 `A. A` / `C. B` 这类错误答案 |
| 1.0.0 | 文档标题被当成题目：`.docx / .txt / .md` 题库首行的标题（如「……练习题库」）会被解析成一道空题，现已过滤 |
| 1.0.0 | OCR 引擎不可用：精简依赖时把 OpenCV 换成了 headless 版，PaddleX 的依赖自检是按发行包名匹配的，导致识别完全起不来。已换成正确的 `opencv-contrib-python` |
| 1.0.0 | Word 97-2003（`.doc`）题库无法导入，且「扩展名是 .docx、实际是 .doc」的文件会直接报错。现按文件头自动分流，`.doc` 用纯 Python 解析（无需装 Word / WPS） |
| 1.0.0 | 中文括号标记写法（`【题型】` / `【答案】` / `【解析】`、题号用 `、`）不被识别；`【答案】B` 还会被当成解析行，导致答案丢失。已支持 |
